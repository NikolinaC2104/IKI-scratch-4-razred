# IKI-scratch-4-razred
Zadatak za IKI stručni razgovor.

## Lov na banane
U ovoj igrici igrač upravlja likom pomoću strelica na tipkovnici.
Cilj je uhvatiti što više banana prije nego što istekne vrijeme.
Za svaku uhvaćenu bananu igrač dobiva jedan bod.
Igra traje 30 sekundi.

## Što koristimo za izradu igrice?
* događaje
* varijable
* petlje
* uvjete
* slučajni položaj
* slanje poruke
